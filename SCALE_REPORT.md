## Layer 4 — qmldir directives dropped

`prefer` redirects every QML file load into the resources compiled
into the style DLL. While it is present the scaled files on disk
are dead code, so it is removed from the vendored copy. `plugin`
is kept — the C++ types still have to register.

- `QtQuick/Controls/FluentWinUI3/qmldir` — dropped `linktarget Qt6::qtquickcontrols2fluentwinui3styleplugin`
- `QtQuick/Controls/FluentWinUI3/qmldir` — dropped `prefer :/qt-project.org/imports/QtQuick/Controls/FluentWinUI3/`
- `QtQuick/Controls/FluentWinUI3/impl/qmldir` — dropped `linktarget Qt6::qtquickcontrols2fluentwinui3styleimplplugin`
- `QtQuick/Controls/FluentWinUI3/impl/qmldir` — dropped `prefer :/qt-project.org/imports/QtQuick/Controls/FluentWinUI3/impl/`
